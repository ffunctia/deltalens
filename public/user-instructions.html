User instruction

Compare with confidence.

Use this page as a quick reference while the comparison workspace remains open in the other tab.

1. Compare two documents

  1. Choose the Original document.
  2. Choose the Updated document.
  3. Select Compare and wait for the page previews to render.
  4. Review the red and blue highlights. They mark the areas that differ between the two files.

Supported files

PDF comparison runs directly in the browser. You can also prepare DOCX, XLSX, PPTX, ODT, ODS, ODP, CSV, and TXT files when the required conversion support is available.

Read the summary

Pages shows how many pages were compared.

Change score estimates the visual area that changed from 0 to 100. A small score can represent a small text edit.

Status describes the size of the detected revision.

AI explanation

AI explanation is optional. Select a provider and enter its API key.

  • Save key stores the key in this browser so you can use it again later.
  • Remove key deletes the saved key from this browser.
  • Enable the consent checkbox before sending any metadata.
  • Choose Explain changes to request a summary.

The explanation receives comparison metadata and excerpts, not the original PDF files.

Privacy and storage

PDF comparison happens locally in your browser. API keys are stored only in this browser's local storage. Use Remove key when you no longer want a key saved here.

For clearer results

  • Use the same page size and orientation in both documents when possible.
  • Keep scans at a similar resolution to reduce layout-only noise.
  • Use the highlights as visual evidence and verify important legal, financial, or compliance changes against the source files.
