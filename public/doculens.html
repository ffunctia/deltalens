User instruction

DocuLens / workflow guide

01 / COMPARE

Upload and compare

  1. Drop or browse for the Original document.
  2. Drop or browse for the Updated document.
  3. Select Start compare and wait for the document scan to finish.
02 / RESULTS

Read the result

Review the side-by-side page previews and the Added, Removed, and Modified visual legend. Pages, Change score, and Status summarize the detected revision.

03 / AI

Explain changes

Select OpenAI, Google Gemini, or Groq, enter an API key, select the privacy consent checkbox, then choose Explain changes. The explanation opens in a scrollable popup.

04 / SUPPORTED

Supported formats

PDF files compare directly in the browser. DOCX, XLSX, PPTX, ODT, ODS, ODP, CSV, and TXT files are supported when the server has LibreOffice available for PDF conversion.

05 / PRIVACY

API keys and privacy

PDF comparison runs locally in the browser. API keys are stored in this browser's local storage. Only minimal comparison metadata and excerpts are sent to the selected AI provider after consent.

06 / RESET

Clear the workspace

Select Reset to remove both selected files, clear comparison results, reset the summary, and prepare the workspace for a new comparison.
